# Контекст проекта: Wordsling

**Суть:** Система Speech-to-Text на базе Gboard.

**Текущий фокус:** Rust-серверная часть проекта — реализация механизма стирания (`_apply_gboard_erase`) с корректным откатом подстановок.

## Текущее состояние пайплайна Wordsling server

Пайплайн полностью собран и работает end-to-end: `TcpServer -> Lexer -> FrankenLab -> ScreenWriter`.

### Состояние FrankenLab / SurgeTable

**Недавние архитектурные улучшения:**
- Механизм Eager Replacement (проактивная замена) полностью реализован и вычищен.
- Операции FSM и модификации досок строго разделены (`_apply_substitution_for_candidate`, `_undo_exact_ready`, `_write_raw_text_to_cutting_board`).
- Убран плавающий `_stabilization_anchor`. Разделочная доска (`_cutting_board`) теперь полностью очищается при стабилизации и содержит *только* нестабильную зону.
- `_prune_if_needed()` применяется только к `_franken_board` (лимит 2000 символов), чтобы сохранять левый контекст для будущих голосовых команд (например, "стереть слово"), избегая переполнения памяти.

**Ожидает реализации (Текущая задача):**
- Обработка забоев от Gboard: функция `_apply_gboard_erase`.

## Утвержденный алгоритм `_apply_gboard_erase` (Стирание блоками справа налево)

При получении команды `[n]` (удалить `n` символов):

1. **Оценка угрозы живому кандидату:**
   - Рассчитываем целевую длину разделочной доски: `target_len = cutting_board.len() - n`.
   - Если кандидат жив и `target_len < candidate._cb_end` (забой пробивает состоявшуюся eager-подстановку): фиксируем кандидата в `_comb` и сбрасываем FSM. Цикл ниже сам разберется с откатом.
   - Если `target_len < candidate._cb_start` (забой стирает самое начало `_Partial` кандидата): просто убиваем кандидата (сбрасываем FSM).
   - *Иначе (забой касается только свободного хвоста после кандидата) - оставляем кандидата в покое.*

2. **Цикл стирания:**
   Пока `n > 0` и разделочная доска не пуста, проверяем конец разделочной доски:

   **Вариант А: Свободный хвост**
   - Если конец доски *не покрыт* последним зубцом из `_comb`, у нас есть свободный сырой текст.
   - Усекаем обе доски на `min(n, длина_хвоста)`.
   - Генерируем `ScreenTransfer::Backspace`.
   - Вычитаем удаленное количество из `n`.

   **Вариант Б: Упор в зубец (подстановку)**
   - Извлекаем последний зубец из `_comb`.
   - Полностью откатываем его подстановку во `franken_board` (вызов `rollback(Before) -> Backspace(fb_len) -> rollback(After)`).
   - Вычисляем, сколько сырых символов ключа мы сейчас стираем: `erased = min(n, cb_len_зубца)`.
   - Усекаем `cutting_board` на `erased`.
   - Вычитаем `erased` из `n`.
   - **Восстановление:** Если часть сырого ключа зубца выжила (`cb_len_зубца - erased > 0`), дописываем этот остаток во `franken_board` и генерируем `ScreenTransfer::Text`.
