# Development interrupted

Андроид-проект находится в более-менее рабочем состоянии, но, похоже, уже устарел, не дойдя до конца разработки.

По ходу работы выяснилось, что Gboard использует в качестве backend-а `SpeechRecognizer`. Из-за этого сама ставка на Gboard как на основу системы, вероятно, была ошибочной с самого начала. Правильнее было бы строить следующую версию сразу на прямом использовании API распознавателя речи.

## Текущее состояние проекта

- знаки препинания превращаются в слова;
- иконка микрофона на клавиатуре нажимается автоматически;
- автоматическое нажатие реализовано пока немного кривовато: через polling состояния клавиатуры раз в 100 миллисекунд;
- больше никакого управления клавиатурой пока не реализовано.
